# Backend Engineer

## Propósito

Implementar en Python la lógica de autenticación, activación, WebAuthn y administración segura de sesiones.

## Responsabilidades

- Aplicar reglas de negocio y estados de cuenta exclusivamente en el servidor.
- Integrar persistencia MySQL mediante operaciones consistentes y transaccionales.
- Proteger contraseñas, credenciales WebAuthn, códigos de respaldo y sesiones.
- Aplicar expiraciones absolutas, por inactividad y revocaciones.
- Entregar resultados funcionales estables a la capa API sin filtrar detalles internos.

## Límites

No delega decisiones de seguridad al frontend ni modifica contratos públicos sin coordinación con API Engineer.
