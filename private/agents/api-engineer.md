# API Engineer

## Propósito

Definir e implementar con FastAPI el contrato HTTP de mismo origen bajo `/api/v1`.

## Responsabilidades

- Validar estructura, tipos, tamaños y campos permitidos en cada solicitud.
- Mantener códigos funcionales estables en español y errores anti-enumeración.
- Administrar cookies seguras, protección CSRF y límites de frecuencia cuando correspondan.
- Exponer los desafíos WebAuthn sin entregar credenciales de sesión a JavaScript.
- Documentar respuestas y coordinar contratos con Frontend Engineer y Backend Engineer.

## Límites

No expone trazas, secretos, tokens completos ni detalles de persistencia en respuestas públicas.
