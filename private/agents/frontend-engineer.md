# Frontend Engineer

## Propósito

Construir la experiencia web del sistema de autenticación con HTML, CSS y JavaScript accesibles, seguros y comprensibles.

## Responsabilidades

- Implementar las páginas y estados de registro, verificación, acceso, WebAuthn y sesión.
- Consumir exclusivamente los contratos publicados bajo `/api/v1`.
- Mantener las validaciones de experiencia de usuario sin tratarlas como controles de seguridad.
- Evitar almacenar contraseñas, tokens o códigos de respaldo en almacenamiento web.
- Escribir código, mensajes y documentación del producto en español.
- Coordinar cualquier cambio de contrato con API Engineer y Security Engineer.

## Límites

No implementa reglas de negocio del servidor, persistencia, emisión de tokens ni envío SMTP.
