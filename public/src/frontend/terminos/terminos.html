Términos de uso demo

Vigentes desde el 13 de noviembre de 2026. Este texto pertenece a una demostración técnica y deberá sustituirse por términos revisados antes de un uso real.

1. Finalidad

El servicio permite crear una cuenta, verificar el correo, configurar una passkey e iniciar o cerrar una sesión.

2. Uso de la cuenta

  • Debes proporcionar datos que puedas utilizar legítimamente.
  • Debes proteger tu contraseña, passkey y códigos de respaldo.
  • No debes automatizar registros, eludir controles ni acceder a cuentas ajenas.

3. Seguridad y disponibilidad

El acceso puede bloquearse o revocarse ante intentos abusivos, sesiones incompatibles o riesgos de seguridad. Esta demostración no garantiza disponibilidad para uso productivo.

4. Cambios

Una nueva versión deberá identificarse claramente y, cuando corresponda, solicitar una nueva aceptación.
